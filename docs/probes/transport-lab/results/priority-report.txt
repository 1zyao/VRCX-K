=== VERDICT ===
  only 0/2 topologies produced >=30 in-transfer samples; treat the rest as indicative
  shared   during max : 130.67 ms (229x idle)
  separate during max : 66.69 ms (139x idle)

  => SHARING is 2.0x worse than a separate connection.
     NEITHER is at idle, and the residual stall on the SEPARATE path is NOT the
     socket: this server pushes the bulk from ONE synchronous send loop, so it
     cannot answer a ping until a slice completes. A real sender must yield in
     bounded slices too, or the SERVER becomes the bottleneck no matter which
     topology the client picks.

  READ THIS BEFORE QUOTING A NUMBER: at least one topology produced FEWER THAN 30 in-transfer samples, so its percentiles are indicative only — raise --frames or lower --pingMs for a quotable figure.
